# Changelog

## 0.9.2

Hello and welcome to SQ Decor!

This is the first public release of the mod for Minecraft 1.21.1 (NeoForge). It brings LEDs and over 100 colorable lamps with a soft 3D glow, switches and remotes to control them, and the blocks and props to build workshops, bunkers, clinics and sci-fi rooms around them.

This is a beta, so expect bugs and changes. Please report problems on GitHub or on our Discord.

Detailed changes will be listed here from the next version on.
